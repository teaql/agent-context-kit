# Coding agent icons

Copied from the companion
[TeaQL Agent Kit](https://github.com/teaql/teaql-agent-kit) so both projects use
the same coding-agent presentation.

The marks originate from
[Lobe Icons](https://github.com/lobehub/lobe-icons),
`@lobehub/icons-static-svg@1.95.1`, under the bundled MIT license. Each mark is
centered on an unchanged white rounded tile for light and dark GitHub themes.
